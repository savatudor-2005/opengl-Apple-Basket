# opengl-Apple-Basket
Acest proiect este o aplicatie grafica 3D interactiva realizata in C si OpenGL. Punctul central este un cos cu mere detaliat. Programul demonstreaza concepte avansate de randare precum iluminarea dinamica, transformari geometrice, umbre planare calculate matematic si controlul interactiv al camerei. Este ideal pentru a invata grafica 3D.
